# dot-life-assets

도트 라이프(개인 노션 워크스페이스)에서 쓰는 도트 아트 에셋 배포 저장소.
원본과 빌드 도구는 로컬 작업 폴더에 있으며, 이 저장소는 배포 스크립트로만 갱신함.

- 아이콘 `icons/*.png` (256×256), 스티커 `stickers/*.png`, 커버 `covers/*.png` (1920×720), 디바이더 `dividers/*.png`, 메뉴 카드 `cards/*.png`
- 목록: `manifest.json`
- 위젯 `widgets/*.html` (노션 /임베드용: today, dday, timer, calendar, weather)
- 폰트(이미지 속 글자): 갈무리 Galmuri (SIL OFL 1.1)
